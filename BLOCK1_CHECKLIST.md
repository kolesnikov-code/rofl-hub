Эффект бустов на добычу и сгорание роботов через 30 дней — Блок 2 (там же чинится расход топлива).

## Как проверить (в этом порядке)

1. Распаковать поверх проекта (или в новую папку), в PyCharm: `pip install -r requirements.txt`.
2. Скопировать `.env.example` → `.env`, заполнить токены, `DATABASE_URL`, `SHOP_TEST_MODE=1`, `SHOP_TEST_USER_IDS=<твой ID>`.
3. Запустить `pytest -q` → ожидается **47 passed** (интеграционные пропускаются без `TEST_DATABASE_URL`).
4. (Желательно) создать пустую тестовую базу, задать `TEST_DATABASE_URL`, снова `pytest -q` → **+8 passed**.
5. Запустить `python -m bots.main_bot.bot`, затем `python -m bots.admin_notifier_bot.bot`.
6. Прогнать сценарии:
   - /start → язык → 4 шага → панель внизу.
   - Магазин → «ДЛЯ ФЕРМЫ» / «ИГРОВЫЕ» → купить **каждый** из 18 товаров в тест-режиме; после покупки Мега-Клана без команды — должен быть отказ ДО выдачи.
   - Купить «Безлимит 24ч», затем выиграть в КНБ больше 15 раз — лимит не срабатывает.
   - Создать команду (нужно 100 000 — купи пак 100k в тест-режиме), выйти из команды — не падает.
   - /all_teams и кнопка «Показать другие команды» — не падает.
   - Викторина → «Новый вопрос» → ответить → повторно нажать старую кнопку → «вопрос не активен».
   - Админ-бот: /new_auction → ссылка в канале открывается; два аккаунта делают ставки по очереди 5 раз; сумма балансов + цена лота неизменна.
   - /close_auction → победитель получил личное сообщение, в канале пост.
