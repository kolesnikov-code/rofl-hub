# Очередь производства квестов (поручение владельца 28.10.2026, ночь — полная самостоятельность)

Порядок: 28 заходов по 5 обычных квестов → 10 эпиков (по 1 за заход). Строго по одному заходу: следующий — только после
проверки (тесты), выкатки и отчёта по предыдущему. Все новые квесты ложатся СКРЫТЫМИ (тумблер quest:<id> / epic:<id>
по умолчанию выключен) — владелец открывает в пульте.

Конвейер на квест (workflow quest-wave): каркас → 2 критика → доработка → автор → 4 проверки (логика, язык/юмор,
слепой плейтест, правила/оригинальность) → правки → финальная приёмка. Бриф — docs/quests/BRIEF.md.
После захода: прогнать tests/test_quests.py и test_minigames.py, обновить ожидаемый список в
test_all_quests_loaded_in_order, все юнит-тесты, коммит, push, проверка деплоя, отчёт владельцу.

Жанры обычных заходов (чередование, детективы ~1/3 банка):
- нечётный заход: классический детектив, детектив с поворотом, комедия, приключение, фантастика;
- чётный заход: детектив (классика или холодное дело), комедия, мистика/лёгкий хоррор, ограбление/триллер, приключение
  или фантастика (через раз).
order обычных: 11, 12, … подряд. Эпики: order 101, 102, …; reward 100, "epic": true, 60–90 сцен, ~60–90 минут.
