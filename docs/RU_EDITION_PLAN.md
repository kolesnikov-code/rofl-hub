# Российская версия ROFL HUB: Яндекс Игры и VK Play (план, 26.10.2026)

Статус владельца: самозанятый в РФ. Его хватает для Яндекс Игр и VK Play. RuStore — позже, нужен ИП.

## Главный принцип

**Один код — две «редакции».** Переключатель `EDITION=telegram | ru` в переменных окружения сервера.
Telegram-версия на Railway продолжает работать как сейчас — каждый шаг выкатывается так, что она
не замечает изменений (по умолчанию `EDITION=telegram`, всё новое выключено).

**Российская версия — отдельный мир:** свой сервер и своя база в России (Яндекс Облако — 152-ФЗ),
своя биржа, ТОП, сезоны, аукционы. Игроки двух миров не пересекаются.

## Где игра сейчас привязана к Telegram (по коду)

| Что | Где | Как отвязываем |
|---|---|---|
| Вход: подпись initData | `shared/webapp_auth.py`, `_ctx`/`_auth_user_id` в 6 модулях API | Общий слой входа: Telegram / Яндекс ID / VK / гость → один `user_id` |
| `user_id` = ID Telegram | таблица `users` и все остальные | Таблица `accounts (provider, external_id) → user_id`; у не-Telegram игроков свои номера из отдельного диапазона |
| Регистрация через /start | `handlers/start.py::register_user` | Регистрация при первом входе в приложение (та же функция, без чата) |
| Оплата Stars | `tg.openInvoice`, `/api/invoice`, `handlers/payments.py` | Общий слой оплаты: каталог тот же, способы — Stars / Яндекс SDK / VK; доставка — тот же `shared/delivery.py` |
| Игры в чате | викторина, КНБ, Больше-Меньше, Сейф, дуэли, квесты (`handlers/*.py`) | Вкладка «🕹 Игры» в приложении; движок выплат (`execute_solo_game_payout`) уже без чата |
| Личные сообщения бота | налёты, награды, биржа, рефералы | Лента «🔔 Уведомления» в приложении (таблица `notices`); в Telegram — по-прежнему ЛС |
| Кнопки Telegram | `tg.BackButton`, `showAlert/showConfirm`, `HapticFeedback`, `openTelegramLink` | Обёртка `platform.*` в index.html: в Telegram — как сейчас, в браузере — свои окна |
| Ссылки наружу | @mister_telebot (16 мест), t.me/share, FAQ/соглашение в отдельной вкладке | В редакции `ru` — убраны; FAQ и соглашение — текстом внутри игры (п. 3.5, 8.4.2 Яндекса) |
| Реальные призы | ручные призы битв, VIP-публикации в Instagram | В редакции `ru` — только внутриигровые награды (п. 3.7 Яндекса) |

## Требования Яндекс Игр, которые закладываем сразу

- Только Яндекс ID + **обязательная игра гостем** с сохранением прогресса (п. 1.2, 1.2.2).
- Покупки только через SDK Яндекса, метод консумирования (п. 1.4, 1.13.1); цены в валюте портала.
- Ни одной ссылки наружу, реклама только через SDK (п. 8.4, 4.1).
- Архив до 100 МБ, `index.html` в корне, имена файлов без кириллицы и пробелов (п. 1.21–1.22).
- Язык — из SDK (п. 2.14); полноэкранный режим, без выделения долгим нажатием и pull-to-refresh (п. 1.6.1, 1.10).

## Этапы

**Этап 1 — фундамент (не меняет Telegram-версию)**
1. `EDITION` в настройках сервера и в index.html (что показывать, какие кнопки).
2. Таблица `accounts` + общий слой входа; Telegram-вход — первый «провайдер», работает как сейчас.
3. Гостевой вход для браузера (для разработки и для Яндекса).
4. Регистрация из приложения (без /start).
5. Обёртка `platform.*` вместо прямых вызовов `tg.*`.

**Этап 2 — игра целиком в приложении**
6. Вкладка «🕹 Игры»: викторина (с таймером 15 с), КНБ, Больше-Меньше, Сейф — на тех же движках.
7. Дуэли и квесты в приложении.
8. Лента уведомлений вместо личных сообщений.

**Этап 3 — Яндекс Игры**
9. Яндекс SDK: вход Яндекс ID, гость, язык, покупки (каталог → товары консоли Яндекса).
10. Сервер и база в Яндекс Облаке, выкатка редакции `ru`.
11. Сборка архива скриптом, черновик в консоли, модерация (3–5 рабочих дней).

**Этап 4 — VK Play Mini**
12. VK-вход и платежи по их документации (сверяем в кабинете разработчика), та же сборка.

**Этап 5 — RuStore** (когда будет ИП): Android-оболочка Capacitor + платежи RuStore.

## Что нужно от владельца

- Название российской версии (уникальное в каталоге Яндекса).
- Аккаунт разработчика Яндекс Игр (самозанятый) — к этапу 3; аккаунт VK Play — к этапу 4.
- Аккаунт Яндекс Облака для сервера и базы — к этапу 3.
