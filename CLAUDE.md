Запуск к 1 ноября 2026: ядро бота на ru/en. Общение — по-русски, сдержанно-юмористически, по делу.

## Правила работы
- Отказоустойчивый код + юнит-тесты на каждое изменение. Перед сдачей: `python -m pytest -q` (Windows, .venv).
- Любое изменение баланса рофлов — ТОЛЬКО через `shared/ledger.change_balance()` внутри транзакции с `FOR UPDATE`.
- Числа экономики — ТОЛЬКО в `shared/economy.py`. Никаких магических чисел в обработчиках.
- Каталог магазина — данные в `bots/main_bot/catalog.py`; у каждого `type` должен быть обработчик в `shared/delivery.py` (тест `test_delivery_contract`).
- Миграции схемы — идемпотентные строки в `shared/database.py::SCHEMA_STATEMENTS`.
- Не упоминать Railway в текстах для игроков. Ввод пользователя в HTML — через `html.escape`.
- Тест-режим магазина только через `.env` (`SHOP_TEST_MODE`, `SHOP_TEST_USER_IDS`); на проде выключен.

## Решения владельца (13.10.2026)
- Лимит побед: викторина 30/сутки, остальные соло-игры 15/сутки, сброс 00:00 UTC.
- Уровни викторины — прогрессивные (против инфляции): уровень N закрывается за N×10 верных
  ответов (счётчик итерации с нуля), награда N×100 рофлов. Уровни 1+2 = ровно дневной лимит,
  с уровня 4 за день без безлимита не успеть — мягкая мотивация покупать снятие лимита за Stars.
- Топливо: Кибер-Бурильщик ест 1 котлету/24ч, при Ядерном разгоне ×3. Добыча: Майнер 5/ч, Бурильщик 10/ч.
- Призы турниров и аукционов — только внутриигровые (рофлы, безлимит, дрон). Выплат Stars нет; тексты о «реальных выплатах» убрать.
- Языки на старте: ru + en через `shared/locales.py`; остальные 11 — после запуска.
